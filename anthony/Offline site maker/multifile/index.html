      About this app
      
    
        
    
          
          
          
        
    
        
    
          
    About Offline Site Saver
    
          
    Version 11.6
    
          
    Saves web pages into a single self-contained HTML file that opens and works with no internet connection. Direct video/audio file links are saved as media files.
    
          
    Runs entirely in your browser — nothing you capture is sent anywhere except to the site you’re copying from. Settings, history and preferences stay on this device.

    Help & Instructions
    
          
    How it works
    
          
      
            
    • It downloads the page, then follows up to 10 links on the same site and downloads those too.
      • 
            
    • Everything is packed into one .html file — open it and click links to move between captured pages, like normal browsing.
      • 
            
    • Paste multiple URLs (one per line) to capture several pages in one batch — each page saves as its own file.
      • 
            
    • A link or search that wasn’t captured will load from the internet if you’re online — otherwise you’ll see a "not saved offline" note.
      • 
            
    • Works best with static pages — sites that load content from a server (live dashboards, real-time feeds, single-page apps) may not capture correctly because the content isn’t present in the HTML.
      • 
            
    • Video and movie streaming (Netflix, YouTube, etc.) cannot be downloaded — they use DRM (digital rights management) and protected streams that can’t be saved to a file.
      • 
            
    • Sites that need a login, or pages built entirely by JavaScript code talking to servers, may not fully capture.
      • 
          
    
          
    Features
    
          
    Basic Capture: Paste a URL, click Capture. Wait for download. One .html file ready.
    
          
    Backgrounds: Pick a preset or drop your own image onto the page.
    
          
    Fonts: Adjust family and size in Settings → Display & style.
    
          
    Log: Toggle the log area with the +/− button.
    
          
    History: Revisit past captures from Settings → Capture history.
    
          
    Languages: Switch in Settings → Language & time.
    
          
    Offline player: Turn your saved audio and video into one playlist page. In Settings → Capture history → Offline player: choose Embed (media is packed inside the page, plays anywhere with nothing else needed) or Link (small page, media files sit next to it in the same folder), press Build player, pick your files, and you get an offline-player.html with a playlist, Prev/Play/Next buttons, auto-advance, and Space / Left / Right keyboard control.
    
          
    Statistics: Press Show stats beside the history buttons for a live dashboard of your captures: total count, total storage, pages vs media files, average size, your biggest captures, and a captures-per-month chart. Press Hide stats to close it.
    
          
    Settings backup: Copy your preferences to another PC. Settings → Backup settings: press Export settings to save a settings JSON file, then on the other PC press Import settings and choose that file → everything applies automatically. Unknown or missing entries fall back to defaults safely.
